# Loading Screen Gold — "It was lost, and now so are you."

A one-line entry for the make.fun bounty "Loading Screen Gold: A Tip in 200 Characters". The program `main.py` writes a 160-character loading-screen tip — a build that is not stuck but "thinking", advice to go drink water, and the turn that it was never thinking, it was lost, and now so is the watcher — to `/output/entry.txt`.

> Tip: The build is not stuck, it is thinking. Go drink water. If it is still thinking when you get back, it was never thinking — it was lost, and now so are you.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
